# COMPOSE — Etapa 1

Projeto acadêmico de Programação Front-End.

## Objetivo
Criar uma vitrine digital simples para uma loja de roupas de bairro, facilitando a visualização de produtos e o contato com a loja.

## Público-alvo
Moradores do bairro interessados em comprar roupas acessíveis.

## Problema
Os clientes nem sempre conseguem consultar os produtos, preços e tamanhos disponíveis sem entrar em contato ou visitar a loja.

## Estrutura
- `index.html`: estrutura e conteúdo do site.
- `css/style.css`: estilos, cores e responsividade.
- `js/script.js`: interação básica do formulário.

## Requisitos implementados
- HTML semântico: header, nav, main, section, article e footer.
- Classes e IDs.
- Box Model com margin, padding, border e box-sizing.
- Flexbox na navegação e no formulário.
- CSS Grid na lista de produtos.
- CSS externo e JavaScript externo.
- Media query para telas menores.
- Formulário inicial com campos obrigatórios.
